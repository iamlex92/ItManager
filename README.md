# ItManager · NetAdmin DCIM

Мобильный центр управления IT-инфраструктурой завода: план здания с кабельной топологией,
коммутаторы Cisco и Eltex, МФУ и регламентные операции. Рассчитан на Google Pixel 10a (Android 16).

Репозиторий содержит два проекта:

| Папка | Что внутри |
| --- | --- |
| `app/` | Android-приложение (Kotlin, Jetpack Compose) |
| `server/` | Сервер NetAdmin (Python, FastAPI), описание API в `server/API.md` |

## Android-приложение

**Стек:** Kotlin 2.2, Jetpack Compose + Material 3, Hilt (внедрение зависимостей), Ktor Client,
kotlinx.serialization, DataStore, Navigation Compose. `minSdk 31`, `targetSdk 36`.
Интерфейс только на русском и только в тёмной теме.

### Что уже есть (этап 1)

- **Карта.** План этажа с жестами: перемещение и масштаб двумя пальцами, инерция после броска,
  мягкое сопротивление у краёв, двойной тап для приближения. Слои L1 (кабели), L2 (VLAN), L3 (IP-подсети),
  фильтр по VLAN. Тап по устройству показывает карточку и подсвечивает путь до коммутатора:
  ПК → розетка → патч-панель → коммутатор.
- **Устройства.** Поиск по имени, IP и MAC, фильтры по типу, переход к устройству на карте.
- **Коммутатор.** Лицевая панель портов как на железе (нечётные сверху, чётные снизу, SFP отдельно),
  цвета по спецификации: зелёный 1/10 Гбит/с, оранжевый 10/100, серый нет линка или shutdown, молния для PoE.
  Карточка порта с режимом, VLAN, скоростью и подключённым устройством. Изменение конфигурации пока недоступно.
- **МФУ.** Уровни тонера и барабана, предупреждение ниже 10 %, проблемные МФУ наверху списка.
- **Автоматизация.** Каталог будущих сценариев (AD, права на папки, резервные копии), без запуска.
- **Настройки.** Адрес сервера, API-токен, проверка соединения, переключатель демо-данных.

### Демо-режим и сервер

По умолчанию включены **демо-данные**: встроенный пример цеха, сервер не нужен,
реальное оборудование не затрагивается. Чтобы работать с сервером:

1. Откройте ⚙ в правом верхнем углу любой вкладки.
2. Укажите адрес сервера, например `10.0.0.5` (порт 8000 подставится сам) или `http://10.0.0.5:8000`.
3. Вставьте API-токен, нажмите «Проверить соединение», выключите демо-данные и сохраните.

Сервер доступен только из сети завода или через VPN и наружу не публикуется.
Поэтому приложение разрешает обычный HTTP (см. `app/src/main/res/xml/network_security_config.xml`).
Когда у сервера появится сертификат внутреннего УЦ, достаточно указать адрес с `https://`.

### Сборка

APK собирается в GitHub Actions на каждый push и pull request: вкладка **Actions** → последний запуск
**Android** → артефакт `itmanager-debug-apk`. Установка на телефон: скачайте APK и откройте его,
разрешив установку из этого источника, или `adb install app-debug.apk`.

Локально нужны JDK 17 и Android SDK (проще всего через Android Studio):

```bash
./gradlew testDebugUnitTest   # юнит-тесты
./gradlew assembleDebug       # app/build/outputs/apk/debug/app-debug.apk
```

### Устройство кода

```
app/src/main/java/com/itmanager/app/
├── core/network     Ktor-клиент, DTO сервера, понятные тексты ошибок
├── core/settings    DataStore с адресом сервера, проверка адреса
├── data/model       Модели предметной области, трассировка кабеля до коммутатора
├── data/source      Демо-данные, работа с сервером, репозиторий
└── ui/
    ├── theme        Цвета, типографика, пружины и жесты (Motion)
    ├── navigation   Нижняя навигация с полупрозрачной панелью
    ├── map          Камера карты (жесты, инерция), отрисовка плана
    ├── devices      Список устройств
    ├── switchdetail Панель портов коммутатора
    ├── printers     МФУ и расходники
    ├── automation   Каталог сценариев
    └── settings     Настройки подключения
```

Анимации построены на пружинах с параметрами Apple (затухание и время отклика) вместо фиксированной
длительности: любое движение можно перехватить пальцем, а после жеста оно продолжается с той же скоростью.
Значения собраны в `ui/theme/Motion.kt`.
