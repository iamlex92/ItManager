NetAdmin

Веб-консоль агента. Всё, что вы внесёте здесь, сразу появится в приложении на телефоне.

Токен показывает команда sudo netadmin-agent info (в Windows: «NetAdmin — подключение телефона»).

      Схема панели
      
    
      Загрузите SVG лицевой панели, выберите порт в списке и щёлкните по его месту на схеме: следующий порт выберется сам.
      «Продолжить ряд» расставит остальные порты ряда с тем же шагом, что у двух предыдущих.
