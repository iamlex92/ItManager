NetAdmin

Веб-консоль агента. Всё, что вы внесёте здесь, сразу появится в приложении на телефоне.

Токен показывает команда sudo netadmin-agent info (в Windows: «NetAdmin — подключение телефона»).

VLAN

Справочник сетей: порты коммутаторов ссылаются на эти номера. Записи инвентаря, на оборудование ничего не отправляется.

VLANНазваниеПодсетьЦветОписание

Сканирование сети

Только чтение: ping, проверка открытых портов, баннеры и SNMP GET. Оборудование не меняется. Запускается только по кнопке.

    Свои скрипты

    Скрипты появляются в приложении на вкладке «Автоматизация». Запуск только в режиме эмуляции: сервер показывает текст с подставленными параметрами и ничего не выполняет.

      Скрипт

      Параметрыв тексте пишите {{имя}}

      Не храните пароли в тексте: для входа на серверы есть раздел «Учётные данные» в приложении.
